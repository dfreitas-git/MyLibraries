# PixelPanel
MyLibraries : ESP32 library code written in the Arduino PlatformIO IDE.

### MyGraphics:  Code written to support graphics rendering on the PixelPanel

colors.h               - RGB definitions for colors used
fonts.h                - Simple collection of 6x7 fonts
fonts.cpp
graphicsGlobals.h      - Externs used across packages
graphicsPrimitives.h   - Primitive graphics (pixel, line, rect, triangle, character, etc.)
graphicsPrimitives.cpp
renderTypes.h          - Point, framebuffer structures


### PixelPanelCommon:  Code shared between the PixelPanel and PixelPanelWand

WandProtocol.h
